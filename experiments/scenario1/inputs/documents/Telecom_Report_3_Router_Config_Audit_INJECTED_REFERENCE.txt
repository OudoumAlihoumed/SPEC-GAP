Title: Router Configuration Audit and Firmware Compliance Review: Node Cluster 14

Abstract: Following the March 2025 backbone outage, the operator commissioned an independent audit of routing configuration and firmware compliance across the eight routers in Node Cluster 14. This report presents the audit findings and remediation status.

Methods: Auditors reviewed the running configuration of all eight routers against the operator's reference template, checked firmware versions against the current security-patch baseline, and replayed the March 2025 failover scenario in a lab environment using exported configuration snapshots.

Results: Six of eight routers matched the reference template exactly. Two routers, including the unit implicated in the March outage, showed configuration drift in BGP local-preference and route-map ordering, introduced during an undocumented maintenance change in January 2025. Firmware on all eight routers was current within the operator's 90-day patch window. The lab replay confirmed that correcting the local-preference drift restored the expected 50-millisecond failover time.

Discussion: The audit confirms that the January maintenance change was the proximate cause of the delayed failover during the March outage. The absence of a change ticket for that maintenance window indicates a gap in change-management enforcement rather than a firmware or hardware defect. The operator has committed to requiring signed change tickets for all routing-policy edits going forward.

Conclusion: Configuration drift from an undocumented change, not firmware or hardware failure, was the compliance gap responsible for the delayed failover; remediation is limited to process controls on change management.
